# Workflow 2.4 — Bersihin Repo dari File Sampah

**Severity:** 🟡 HIGH
**Estimasi:** 0,5 hari
**Dependensi:** —

---

## Langkah

### 1. Hapus File dari Git

```bash
cd /home/marco/ARO-DRIVE

# Scratch scripts
git rm -rf functions/scratch/
git rm -rf scratch/
git rm batch_scan.js scratch-test-orders.js

# Python scripts di pages/
git rm aro-drive-vite/src/pages/*.py
git rm aro-drive-vite/src/pages/*.txt
git rm aro-drive-vite/src/pages/*.json

# File lain
git rm output.log "notif driver.mp3" brosur_aro_drive.png aro-driver-kotlin.zip
```

### 2. Commit

```bash
git commit -m "chore: clean up repo — remove scratch files, scripts, and binaries"
```

### 3. Update .gitignore

Tambah ke `.gitignore`:

```
# Temp & development
temp/
tmp/
*.log
output.log

# Scripts yang tidak perlu di repo
*.py
*.ipynb

# Binaries
*.zip
*.apk
*.aab
*.mp3
*.png
*.jpg
```

- [ ] `functions/scratch/` sudah tidak ada
