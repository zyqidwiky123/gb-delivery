# Workflow 4.4 — Data Room untuk Pembeli (Opsional)

**Severity:** 📘 LOW
**Estimasi:** 1-2 hari
**Dependensi:** Semua Fase 1-3

---

## Latar Belakang

Data Room adalah kumpulan dokumen yang diberikan ke calon pembeli untuk due diligence. **Tidak dimasukkan ke git repo** — dikirim langsung ke pembeli via Google Drive / email.

---

## Langkah

### 1. Buat Folder Data Room (di luar repo)

```bash
mkdir -p ~/Desktop/ARO-DRIVE-Data-Room
```

### 2. Dokumen yang Dibuat

**01-Executive-Summary.md → PDF**

```markdown
# ARO DRIVE — Executive Summary

## Produk
Platform on-demand delivery & transportasi online.
5 aplikasi (User, Admin, Driver Android, Mitra, Landing).

## Tech Stack
- Frontend: React 19, Vite 6, Zustand, Tailwind
- Mobile: Kotlin, Compose, MVVM
- Backend: Node.js 22, Firebase (Firestore, RTDB, Storage, Functions v2)
- Infra: Google Cloud Platform (Cloud Run, Pub/Sub, Cloud Scheduler)

## Fitur Unggulan
- Dispatch system radius expansion
- Image processing (WebP, Google Vision API)
- Real-time driver tracking
- Full admin dashboard

## Status
- Siap deploy
- Source code + Firebase config included
- Dokumentasi setup lengkap
```
