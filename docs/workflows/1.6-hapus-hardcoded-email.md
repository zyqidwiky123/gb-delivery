# Workflow 1.6 — Hapus Hardcoded Admin Email

**Severity:** 🔴 KRITIS
**Estimasi:** 0,5 hari
**Dependensi:** —

---

## Latar Belakang

`aro-admin-vite/src/pages/Login.jsx` baris ~34, 51:

```javascript
if (email === 'zyqidwiky@gmail.com') { ... }
```

**Risiko:**
- Hanya 1 email yang bisa jadi admin
- Email ter-expose di source code
- Tidak bisa delegasi ke orang lain

---

## Langkah

### 1. Edit Login.jsx

Hapus semua pengecekan `email === 'zyqidwiky@gmail.com'`.

Ganti dengan role lookup dari Firestore:

```javascript
// Setelah login sukses, cek role user
const userDoc = await getDoc(doc(db, 'users', user.uid));
const role = userDoc.data()?.role;

if (role !== 'admin') {
    // Sign out & kasih pesan error
    await signOut(auth);
    alert('Akun ini tidak memiliki akses admin');
    return;
}

// Set admin state
setIsAdmin(true);
```

### 2. Pastikan Firestore Rules Support

Pastikan di `firestore.rules` ada:

```javascript
match /users/{userId} {
  allow read: if request.auth.uid == userId || isAdmin();
  allow write: if request.auth.uid == userId;
}
```

### 3. Deploy

```bash
firebase deploy --only hosting:aro-drive-admin
```

### 4. Test

- [ ] Login dengan `zyqidwiky@gmail.com` yang punya role `admin` → bisa akses
- [ ] Login dengan email lain yang punya role `admin` → bisa akses
- [ ] Login dengan email tanpa role admin → ditolak
