# Workflow 2.1 — Split Backend index.js

**Severity:** 🟡 HIGH
**Estimasi:** 2-3 hari
**Dependensi:** — (bisa jalan paralel dengan Fase 1)

---

## Latar Belakang

`functions/index.js` = **2.254 baris** dalam 1 file. Semua logika bisnis di sini: dispatch system, order lifecycle, merchant photo processing, admin endpoints, dll.

---

## Langkah

### 1. Buat Struktur Folder

```
functions/
├── src/
│   ├── index.js           → main exports (re-export dari modules)
│   ├── dispatch.js        → dispatchOrder, dispatchToDriver
│   ├── orders.js          → onOrderCreated, onOrderUpdate
│   ├── drivers.js         → autoOffline, resetDailyOnline, syncOnline
│   ├── merchants.js       → fetchPhotoFromMaps, syncPopularity
│   ├── notifications.js   → Fonnte, FCM templates
│   ├── pricing.js         → calculateFee, calculateAppFee, pickupFee
│   ├── admin.js           → deleteUser, deleteMerchant, receiveCrash
│   ├── validation.js      → input validation helpers
│   └── utils.js           → haversine, parseCoords, dll
└── index.js               → entry point (re-export semua fungsi)
```

### 2. Pindah Fungsi Satu per Satu

Untuk setiap modul:

```
a. Potong fungsi dari index.js (old)
b. Paste ke src/<module>.js
c. Bungkus dalam exports
d. Panggil dari index.js (new)
```

### 4. index.js (baru)

Setelah semua dipindah, `index.js` cuma berisi:

```javascript
const functions = require("firebase-functions");
const admin = require("firebase-admin");

admin.initializeApp({ ... });

// Export semua fungsi dari modules
exports.onOrderCreated = require("./src/orders").onOrderCreated;
exports.onOrderUpdate = require("./src/orders").onOrderUpdate;
exports.autoOfflineLongOnlineDrivers = require("./src/drivers").autoOfflineLongOnlineDrivers;
// ... dan seterusnya
```

### 5. Handle Lazy Imports

Untuk library berat (`axios`, `sharp`, `@google-cloud/vision`), pakai lazy pattern:

```javascript
// src/merchants.js
let _sharp;
function getSharp() {
    if (!_sharp) _sharp = require('sharp');
    return _sharp;
}
```
