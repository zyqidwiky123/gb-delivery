# Workflow 2.2 — Split Admin Dashboard

**Severity:** 🟡 HIGH
**Estimasi:** 2-3 hari
**Dependensi:** —

---

## Latar Belakang

`aro-admin-vite/src/pages/Dashboard.jsx` = **3.333 baris**. Semua fitur admin di sini: overview, driver management, merchant management, user management, orders, banners, promos, vouchers, pricing settings, transactions.

---

## Langkah

### 1. Install React Router (jika belum)

```bash
cd aro-admin-vite
npm install react-router-dom
```

### 2. Buat Halaman Terpisah

Buat file baru di `src/pages/`:

| File | Isi |
|:-----|:----|
| `DashboardOverview.jsx` | Ringkasan + stats (ambil dari tab "Overview") |
| `DriverManagement.jsx` | CRUD driver, topup, lihat transaksi |
| `MerchantManagement.jsx` | CRUD merchant, menu, foto |
| `UserManagement.jsx` | CRUD user, lihat history |
| `OrderManagement.jsx` | Lihat & filter order |
| `PromotionManagement.jsx` | Banner, promo, voucher |
| `PricingSettings.jsx` | Tarif & fee settings |
| `TransactionHistory.jsx` | Semua transaksi |

### 3. Pindah State ke Store

Buat `src/store/dashboardStore.js`:

```javascript
import { create } from 'zustand';

const useDashboardStore = create((set) => ({
    // State dari Dashboard.jsx
    drivers: [],
    merchants: [],
    orders: [],
    revenue: 0,
    activeDrivers: 0,
    
    // Actions
    fetchDrivers: async () => { ... },
    fetchMerchants: async () => { ... },
    // ...
}));
```

### 4. Setup Routing di App.jsx

```javascript
import { BrowserRouter, Routes, Route } from 'react-router-dom';

function App() {
    return (
        <BrowserRouter>
            <Routes>
                <Route path="/admin/dashboard" element={<DashboardOverview />} />
                <Route path="/admin/drivers" element={<DriverManagement />} />
                <Route path="/admin/merchants" element={<MerchantManagement />} />
                <Route path="/admin/users" element={<UserManagement />} />
                <Route path="/admin/orders" element={<OrderManagement />} />
                <Route path="/admin/promotions" element={<PromotionManagement />} />
                <Route path="/admin/pricing" element={<PricingSettings />} />
                <Route path="/admin/transactions" element={<TransactionHistory />} />
                <Route path="*" element={<Navigate to="/admin/dashboard" />} />
            </Routes>
        </BrowserRouter>
    );
}
```

### 5. Metode Split per Tab

Untuk setiap tab di Dashboard.jsx lama:

```
1. Potong seluruh JSX untuk tab tersebut (misal tab "Drivers")
2. Buat file baru DriverManagement.jsx
3. Pindah state & logic yang terkait
4. Ganti tab dengan Route
5. Test fitur
```

### 6. Test

```bash
cd aro-admin-vite
npm run dev
# Test setiap halaman
```
