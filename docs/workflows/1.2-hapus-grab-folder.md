## Langkah

```bash
cd /home/marco/ARO-DRIVE
git rm -rf aro-driver-kotlin/grab-driver/
```

### 2. Hapus File Besar Lain

```bash
git rm aro-driver-kotlin.zip
git rm scratch/merchants_api.json
git rm output.log
```

### 3. Update .gitignore

Tambah di `.gitignore`:

```
# APK & binaries
*.apk
*.aab
*.zip
*.tar.gz

# Log
*.log

aro-driver-kotlin/grab-driver/
```

### 4. Hapus dari Git History (BFG)

```bash
java -jar bfg.jar --delete-folders grab-driver .
java -jar bfg.jar --delete-files "*.zip" .
java -jar bfg.jar --delete-files "*merchants_api.json" .

git reflog expire --expire=now --all
git gc --prune=now --aggressive
```

### 5. Push

```bash
git push origin --force --all
```
