# Workflow 4.3 — Git History Cleanup

**Severity:** 📘 LOW
**Estimasi:** 1 hari
**Dependensi:** Semua Fase 1-3

---

## Latar Belakang

Git history mengandung file-file yang seharusnya tidak pernah masuk repo:

- API Key di `gmaps api.txt`
- API Key di `scratch/merchants_api.json`
- Competitor APK di `aro-driver-kotlin/grab-driver/`
- Binary files (`*.zip`, `*.apk`)
- File development sementara

---

## Langkah

### 1. Install BFG Repo-Cleaner

```bash
# Download BFG
wget https://repo1.maven.org/maven2/com/madgag/bfg/1.14.0/bfg-1.14.0.jar -O bfg.jar

# Atau via brew
brew install bfg
```

### 2. Buat Fresh Clone (WAJIB — BFG tidak bisa di working repo)

```bash
cd /tmp
git clone --mirror <repo-url> aro-drive-cleanup.git
cd aro-drive-cleanup.git
```

### 3. Hapus File dari History

```bash
# Hapus folder
java -jar bfg.jar --delete-folders grab-driver .
java -jar bfg.jar --delete-folders scratch .

# Hapus file spesifik
java -jar bfg.jar --delete-files "gmaps api.txt" .
java -jar bfg.jar --delete-files "merchants_api.json" .
java -jar bfg.jar --delete-files "*.zip" .
java -jar bfg.jar --delete-files "*.apk" .
java -jar bfg.jar --delete-files "*.aab" .
java -jar bfg.jar --delete-files "output.log" .

# Hapus file besar > 10MB
java -jar bfg.jar --strip-blobs-bigger-than 10M .
```

### 4. Bersihkan & Push

```bash
# Git cleanup
git reflog expire --expire=now --all
git gc --prune=now --aggressive

# Verifikasi ukuran
git count-objects -vH

# Push
git push origin --force --all
git push origin --force --tags
```

### 5. Bersihin Local Repo

```bash
cd /home/marco/ARO-DRIVE
# Pull dari mirror yang sudah bersih
git fetch origin
git reset --hard origin/main

# Atau clone ulang
cd ..
mv ARO-DRIVE ARO-DRIVE-old
git clone <repo-url>
```

### 6. Verifikasi

```bash
# Cek history tidak ada file yang dihapus
git log --all --oneline --diff-filter=D -- "*gmaps*"
git log --all --oneline --diff-filter=D -- "*grab*"

# Ukuran repo
git count-objects -vH
```

### Verifikasi

- [ ] BFG sudah dijalankan
- [ ] Mirror clone sudah di-push
- [ ] Local repo di-reset atau clone ulang
- [ ] Ukuran repo turun drastis
- [ ] Tidak ada API key / file besar di history
