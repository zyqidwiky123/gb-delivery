# Workflow 3.1 — License File

**Severity:** 🟢 MEDIUM
**Estimasi:** 0,5 hari
**Dependensi:** —

---

## Langkah

### 1. Buat LICENSE di Root Repo

Pilih salah satu:

**Opsi A: MIT License (untuk open source)**

```
MIT License

Copyright (c) 2026 [Nama Anda / Perusahaan Anda]

Permission is hereby granted...
(dst — teks standar MIT)
```

**Opsi B: Proprietary / All Rights Reserved (untuk commercial sale)**

```
Copyright (c) 2026 [Nama Anda / Perusahaan Anda]

All rights reserved. This source code is not open source
and may not be copied, distributed, or modified without
explicit written permission from the copyright holder.
```

### 2. Update package.json

Di root `package.json`:

```json
{
    "license": "MIT",  // atau "UNLICENSED" untuk proprietary
    "private": true
}
```

Ulangi untuk subproject:
- `functions/package.json`
- `aro-drive-vite/package.json`
- `aro-admin-vite/package.json`
- `aro-driver-kotlin/app/build.gradle`

### 3. Hapus LICENSE Lama

```bash
git rm aro-admin-vite/LICENSE
# atau update copyright-nya
```

### 4. Commit

```bash
git add LICENSE
git add -u
git commit -m "chore: add root license file"
```

### Verifikasi

- [ ] `LICENSE` ada di root repo
- [ ] `package.json` semua subproject punya field `license`
- [ ] Copyright nama sudah sesuai
- [ ] LICENSE lama di aro-admin-vite sudah dihapus/diupdate
