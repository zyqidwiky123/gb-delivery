# Workflow 1.3 — Tambah Auth Guard ke Admin Endpoint

**Severity:** 🔴 KRITIS
**Estimasi:** 0,5 hari
**Dependensi:** —

---

## Latar Belakang

4 HTTP endpoints di `functions/index.js` **TIDAK** punya autentikasi. Siapapun yang tahu URL-nya bisa:

- `syncMerchantPopularityFromMaps` → pakai Google Maps API atas biaya Anda
- `fetchMerchantPhotoFromMaps` → pakai Google Maps + Vision API
- `processAllExistingMerchants` → proses SEMUA merchant (bisa abuse)
- `migrateImagesToWebP` → migrasi massal (bisa abuse)

Fungsi `verifyAdminRequest()` **SUDAH ADA** di kode — tinggal dipanggil.

---

## Langkah

### 1. Buka functions/index.js

Cari 4 fungsi berikut:

```
exports.syncMerchantPopularityFromMaps = ...
exports.fetchMerchantPhotoFromMaps = ...
exports.processAllExistingMerchants = ...
exports.migrateImagesToWebP = ...
```

### 2. Tambah Auth Guard

Di setiap fungsi, tambahkan di **baris pertama setelah `async (req, res) => {`**:

```javascript
const authResult = await verifyAdminRequest(req);
if (!authResult.success) {
    res.status(401).json({ error: authResult.error });
    return;
}
```

### 3. Contoh Hasil Akhir

```javascript
exports.syncMerchantPopularityFromMaps = onRequest(
    { cors: true, region: "asia-southeast2" },
    async (req, res) => {
        // === AUTH GUARD ===
        const authResult = await verifyAdminRequest(req);
        if (!authResult.success) {
            res.status(401).json({ error: authResult.error });
            return;
        }

        // ... existing code ...
    }
);
```

Ulangi untuk 3 fungsi lainnya.

### 4. Deploy

```bash
firebase deploy --only functions
```

### 5. Test

```bash
# Test tanpa auth — harus 401
curl -X POST https://asia-southeast2-gb-delivery-41bf6.cloudfunctions.net/syncMerchantPopularityFromMaps
# Response: {"error": "Unauthorized"} (401)

# Test dengan token invalid — harus 401
curl -X POST -H "Authorization: Bearer invalid" <url>
# Response: 401
```
