# Workflow 3.5 — Perbaiki Inline require()

**Severity:** 🟢 MEDIUM
**Estimasi:** 0,5 hari
**Dependensi:** 2.1 (split index.js)

---

## Latar Belakang

Library `axios`, `sharp`, `@google-cloud/vision` di-require secara inline di dalam function body. Ini menyebabkan:

- Module di-load berulang kali setiap fungsi dipanggil
- Kode kurang rapi

```javascript
// ❌ INLINE — dipanggil tiap fungsi dieksekusi
const result = await require('sharp')(imageBuffer)
    .resize(800)
    .webp({ quality: 80 })
    .toBuffer();
```

---

## Langkah

### 1. Ganti dengan Top-Level require

```javascript
// ✅ TOP-LEVEL — sekali di awal
const sharp = require('sharp');
```

Atau pakai lazy initialization pattern (untuk mengurangi cold start):

```javascript
// ✅ LAZY INIT — sekali, pas pertama dipakai
let _sharp;
function getSharp() {
    if (!_sharp) _sharp = require('sharp');
    return _sharp;
}
```
