## Langkah

### 1. Revoke API Key Lama

```
1. Buka https://console.cloud.google.com/apis/credentials
2. Cari API Key: AIzaSyAMdIaOkJQ8t_rokwEDkBWTJjjw9tmYzUk
3. Klik "Delete" → revoke key lama
4. Confirm
```

### 2. Buat API Key Baru

```
1. Klik "Create Credentials" → "API Key"
2. Copy key baru (simpan sementara)
3. Klik "Restrict Key"

4. Application restrictions — pilih salah satu:
   - HTTP referrers (untuk web app):
     *.web.app/*
     localhost/*
   - Atau IP addresses (untuk development)

5. API restrictions:
   ✓ Maps JavaScript API
   ✓ Places API
   ✓ Directions API
   ✓ Geocoding API
   (JANGAN centang yang tidak dipakai)
```

### 3. Update Semua File .env

Update key di file berikut:

| File | Yang diedit |
|:-----|:------------|
| `.env` (root) | `VITE_GOOGLE_MAPS_API_KEY` |
| `aro-drive-vite/.env` | `VITE_GOOGLE_MAPS_API_KEY` |
| `aro-admin-vite/.env` | `VITE_GOOGLE_MAPS_API_KEY` |
| `aro-admin-vite/.env.production` | `VITE_GOOGLE_MAPS_API_KEY` |

### 4. Update .env.example

Ganti semua contoh API key jadi placeholder:

```
VITE_GOOGLE_MAPS_API_KEY="YOUR_GOOGLE_MAPS_API_KEY"
```

File:

- `.env.example` (root)
- `aro-drive-vite/.env.example`
- `aro-admin-vite/.env.example`
- `aro-admin-vite/.env.production.example`

### 5. Hapus API Key Lama dari Git History

```bash
# Hapus file yang pernah berisi API key
java -jar bfg.jar --delete-files "gmaps api.txt" .

# Hapus merchants_api.json yang mengandung key
java -jar bfg.jar --delete-files "merchants_api.json" .

# Bersihkan
git reflog expire --expire=now --all
git gc --prune=now --aggressive
```

### 6. Push & Verifikasi

```bash
git push origin --force --all
```

Verifikasi:
- [ ] Key lama sudah direvoke
- [ ] Key baru sudah terbatasi
- [ ] .env files sudah pakai key baru
- [ ] .env.example pakai placeholder
- [ ] Git history bersih dari key lama
