# Workflow 3.3 — CI/CD Cleanup

**Severity:** 🟢 MEDIUM
**Estimasi:** 1 hari
**Dependensi:** —

---

## Latar Belakang

Saat ini ada **5 workflow file**, 3 di antaranya build APK secara duplikatif:

| File | Trigger | Masalah |
|:-----|:--------|:--------|
| `deploy.yml` | Push ke main | ✅ Main deployment |
| `build.yml` | PR/push ke main | ❌ Duplikasi build APK |
| `release.yml` | GitHub Release publish | ❌ Duplikasi build APK |
| `build-release.yml` | Tag v* | ❌ Duplikasi build APK |
| `aro-driver-kotlin/.github/workflows/build.yml` | Tag v* | ❌ Duplikasi (sama) |

Juga: `deploy.yml` mencoba build `aro-drive-driver-vite` & `aro-drive-mitra-vite` yang tidak ada.

---

## Langkah

### 1. Hapus Workflow Duplikat

```bash
rm .github/workflows/build.yml
rm .github/workflows/release.yml
rm aro-driver-kotlin/.github/workflows/build.yml
```

### 2. Update deploy.yml

Hapus step:

```yaml
# HAPUS — app ini tidak ada
- name: Build & Deploy ARO Driver
  ...
  working-directory: aro-drive-driver-vite
  continue-on-error: true  # <-- ini masking error!

# HAPUS — app ini tidak ada
- name: Build & Deploy ARO Mitra
  ...
  working-directory: aro-drive-mitra-vite
  continue-on-error: true
```

Tambahkan test & lint stage:

```yaml
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: cd functions && npm ci && npm test
      - run: cd aro-drive-vite && npm ci && npm test
      - run: cd aro-admin-vite && npm ci && npm run lint

  deploy:
    needs: test
    runs-on: ubuntu-latest
    # ... existing deploy steps
```

### 3. Update firebase.json

Hapus 2 hosting entry yang tidak ada app-nya:

```json
// HAPUS
{
    "site": "aro-drive-driver",
    "public": "aro-drive-driver-vite/dist",
    ...
},
{
    "site": "aro-drive-mitra",
    "public": "aro-drive-mitra-vite/dist",
    ...
}
```

Atau biarkan dengan `public` mengarah ke folder `coming-soon/`.

### 4. Commit

```bash
git add .
git commit -m "chore: consolidate CI/CD workflows and remove unused app targets"
```
