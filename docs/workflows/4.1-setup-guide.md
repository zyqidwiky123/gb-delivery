# Workflow 4.1 — Setup Guide

**Severity:** 📘 LOW
**Estimasi:** 1 hari
**Dependensi:** Semua Fase 1-3

---

## Langkah

### 1. Buat docs/SETUP.md

```markdown
# ARO DRIVE — Panduan Setup

## Prasyarat

| Tool | Versi Minimal | Cara Install |
|:-----|:-------------|:-------------|
| Node.js | 22+ | `nvm install 22` |
| Java | 17+ | `apt install openjdk-17-jdk` |
| Firebase CLI | 13+ | `npm install -g firebase-tools` |
| gcloud CLI | — | [cloud.google.com/sdk](https://cloud.google.com/sdk) |
| Android Studio | — | Untuk build APK |

## Langkah Cepat (30 menit)

### 1. Clone & Install

```bash
git clone <repo-url>
cd ARO-DRIVE
npm install
cd functions && npm install
cd ../aro-drive-vite && npm install
cd ../aro-admin-vite && npm install
```

### 2. Buat Firebase Project

1. Buka https://console.firebase.google.com
2. Klik "Add Project"
3. Isi nama (misal "ARO-DRIVE-Production")
4. Enable Google Analytics (opsional)
5. Tunggu provisioning selesai

### 3. Enable Services

Di Firebase Console → Build:

| Service | Yang Diaktifkan |
|:--------|:----------------|
| Authentication | Email/Password, Google, Phone |
| Firestore | Mode native, lokasi asia-southeast1 |
| Realtime Database | Lokasi asia-southeast1 |
| Storage | Mulai dengan mode test |
| Functions | Upgrade ke Blaze plan (wajib billing) |
| Hosting | Install firebase tools |

### 4. Setup Google Maps API

1. Buka https://console.cloud.google.com/apis/credentials
2. Buat API Key baru
3. Batasi: Maps JavaScript API, Places API, Directions API
4. Copy key

### 5. Konfigurasi Environment

```bash
# Root
cp .env.example .env
# isi: VITE_GOOGLE_MAPS_API_KEY=key_dari_langkah_4

# User app
cp aro-drive-vite/.env.example aro-drive-vite/.env
# isi semua variable

# Admin app
cp aro-admin-vite/.env.example aro-admin-vite/.env
cp aro-admin-vite/.env.production.example aro-admin-vite/.env.production
# isi semua variable
```

### 6. Firebase Init

```bash
firebase login
firebase use --add
# pilih project yang baru dibuat

firebase init
# Pilih: Firestore, Functions, Hosting, Storage, Realtime Database
# Functions: pilih existing (functions/)
# Hosting: pilih "Set up later" (kita sudah punya firebase.json)
```

### 7. Deploy

```bash
firebase deploy
```

### 8. Seed Data

```bash
node aro-drive-vite/scripts/seedSystem.js
```

### 9. Setup Android App

1. Buka `aro-driver-kotlin/` di Android Studio
2. Ganti `google-services.json` dengan punya project baru
3. Ganti `strings.xml` → `maps_api_key`
4. Buat signing key: `keytool -genkey -v -keystore release.keystore`
5. Build: `./gradlew assembleRelease`

### 10. Verifikasi

- [ ] Buka `https://<project>.web.app` — landing page tampil
- [ ] Buka `https://aro-drive-user.web.app` — bisa login
- [ ] Buka `https://aro-drive-admin.web.app` — bisa login & lihat dashboard
- [ ] Android app build sukses

## Troubleshooting

| Masalah | Solusi |
|:--------|:-------|
| Functions error "billing not enabled" | Upgrade ke Blaze plan di Firebase Console |
| Hosting 404 | Pastikan firebase deploy sukses |
| Google Maps tidak tampil | Cek API key restriction (referrer) |
| Android Maps kosong | Isi `maps_api_key` di `strings.xml` atau Remote Config |
```
