## Langkah

### 1. Buat Shared Package

```bash
mkdir -p packages/shared
cd packages/shared
```

### 2. package.json

```json
{
    "name": "@aro/shared",
    "version": "1.0.0",
    "private": true,
    "main": "index.js",
    "dependencies": {
        "firebase": "^12.0.0",
        "react": "^19.0.0"
    }
}
```

### 3. Pindah File

| File Sumber | → | File Shared |
|:------------|:--|:------------|
| `aro-drive-vite/src/utils/mapConfig.js` | → | `packages/shared/mapConfig.js` |
| `aro-drive-vite/src/components/LocationPickerModal.jsx` | → | `packages/shared/LocationPickerModal.jsx` |
| `aro-drive-vite/src/firebase/config.js` | → | `packages/shared/firebase.js` |
| `aro-drive-vite/src/store/adminStore.js` → `calculateFee()` | → | `packages/shared/pricing.js` |
| `aro-drive-vite/src/pages/AdminOrderCreate.jsx` | → | `packages/shared/AdminOrderCreate.jsx` |

### 4. Link ke Kedua App

`aro-drive-vite/package.json` dan `aro-admin-vite/package.json`:

```json
{
    "dependencies": {
        "@aro/shared": "file:../packages/shared"
    }
}
```

### 5. Update Import

Di kedua app, ganti import:

```javascript
// OLD
import { mapConfig } from '../../utils/mapConfig';

// NEW
import { mapConfig } from '@aro/shared/mapConfig';
```

### 6. Hapus File Duplicate

```bash
# User app
rm aro-drive-vite/src/utils/mapConfig.js
rm aro-drive-vite/src/components/LocationPickerModal.jsx
rm aro-drive-vite/src/firebase/config.js
rm aro-drive-vite/src/pages/AdminOrderCreate.jsx

# Admin app
rm aro-admin-vite/src/utils/mapConfig.js
rm aro-admin-vite/src/components/LocationPickerModal.jsx
rm aro-admin-vite/src/firebase/config.js
rm aro-admin-vite/src/pages/AdminOrderCreate.jsx
```

### 7. Test

```bash
cd aro-drive-vite && npm run dev   # harus jalan
cd aro-admin-vite && npm run dev   # harus jalan
```

- [ ] `packages/shared/` berisi semua kode shared
